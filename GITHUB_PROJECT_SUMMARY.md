# GitHub Project Summary

## Short Description

Turn one-line product requests into history-compatible PRD and AI-ready OpenSpec handoff artifacts.

## Medium Description

`product-requirement-foundry` is a requirement-generation skill package for teams that want AI to produce useful PRD and spec artifacts without losing historical product context.

It supports:

- `0->1` greenfield requirement generation
- `1->n` incremental requirement generation for live products
- historical baseline loading from PRD, wiki, OpenSpec, knowledge assets, API, tracking, and enterprise documentation
- confidence scoring, evidence chains, and review gates
- OpenSpec proposal/design/spec/tasks/dev-context handoff for AI-assisted development
