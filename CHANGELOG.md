# Changelog

## 0.1.1 - 2026-05-13

- Renamed the package from `baseline-aware-prd` to `product-requirement-foundry`.
- Unified package branding across directory name, `SKILL.md`, CLI help text, README files, examples, and references.
- Added a bilingual project identity with English and Chinese naming, slogan, and project summary.
- Added open-source collaboration documents: `CONTRIBUTING.md` and `CODE_OF_CONDUCT.md`.
- Added GitHub-ready project summary documents in English and Chinese.
- Rebuilt `README.zh-CN.md` to fix corrupted Chinese content and restore clean UTF-8 text.

## 0.1.0 - 2026-05-12

- Added Product Requirement Foundry workflow for `0->1` and `1->n` requirements.
- Added baseline scanner for historical PRD, wiki, OpenSpec, knowledge, API, tracking, and glossary sources.
- Added OpenSpec output adapter with proposal, design, spec, tasks, and development context templates.
- Added confidence scoring and review gates for product and engineering handoff.
- Added starter workspace for new requirement intake.
- Added social-domain pack and social incremental examples.
- Added CLI commands for `init`, `scan`, and `score`.
