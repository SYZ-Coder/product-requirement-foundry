# Requirement Intake

## One-Line Request

Prioritize comments from close connections on the feed detail page.

## Product Context

- Product: social-app
- Domain: social
- Platforms: iOS, Android
- Requirement type: incremental-feature

## Expected Output

- PRD for development
- OpenSpec proposal/design/spec/tasks/dev-context
- Confidence report

## Known Background

Users currently see comments ranked by relevance and creation time. Product wants comments from close connections to appear earlier so users can notice familiar voices first.
