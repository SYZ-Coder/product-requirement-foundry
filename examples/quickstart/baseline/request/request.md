# Requirement Request

## One-Line Request

Prioritize comments from close connections on the feed detail page.

## Product

- Product name: social-app
- Domain: social
- Platforms: iOS, Android, Web

## Intent

When a user opens the feed detail page, comments from people with stronger relationship signals should appear earlier, without breaking existing moderation, ranking fallback, or interaction behavior.

## Expected Output

- Incremental PRD
- OpenSpec handoff package
- Confidence report

## Constraints

- Must remain compatible with current comment ranking fallback behavior.
- Must not change moderation visibility rules.
- Must consider tracking impact.
- Must preserve existing social terminology.
