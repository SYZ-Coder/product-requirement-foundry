# Tool Prompt Templates

These templates are ready-to-copy starting prompts for different AI tools.

Included templates:

- [Codex](./codex-prompt.md)
- [Cursor](./cursor-prompt.md)
- [GitHub Copilot](./copilot-prompt.md)
- [Claude Code](./claude-code-prompt.md)

How to use:

1. Replace `<workspace-dir>` with your real requirement workspace.
2. Open the target AI tool.
3. Paste the matching template.
4. Let the tool read `baseline/` first, then generate `docs/output/`.
