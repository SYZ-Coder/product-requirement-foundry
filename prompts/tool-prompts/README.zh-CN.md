# 工具提示词模板

这里提供的是可以直接复制粘贴到不同 AI 工具中的标准提示词模板。

已包含：

- [Codex](./codex-prompt.md)
- [Cursor](./cursor-prompt.md)
- [GitHub Copilot](./copilot-prompt.md)
- [Claude Code](./claude-code-prompt.md)

使用方式：

1. 把 `<workspace-dir>` 替换成你的真实需求工作区路径。
2. 打开目标 AI 工具。
3. 粘贴对应模板。
4. 让工具先读取 `baseline/`，再生成 `docs/output/`。
