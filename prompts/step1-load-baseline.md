# Step 1: Load Baseline

You are preparing to generate a requirement document. Before writing anything final, load the historical baseline.

## Tasks

1. Read the user request.
2. Identify the most relevant historical sources.
3. Extract:
   - existing modules
   - existing features
   - pages
   - APIs
   - entities
   - events
   - business constraints
   - technical constraints
   - key terminology
4. Produce:
   - `baseline-summary.md`
   - `feature-inventory.json`
   - `historical-requirements.json`
   - `known-constraints.json`
   - `glossary.json`

## Rules

- Prefer official, approved, and newer documents.
- Record conflicts instead of silently merging them.
- Distinguish fact from inference.
