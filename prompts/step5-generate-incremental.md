# Step 5: Generate Incremental PRD

Use this for `incremental-feature`, `cross-module-change`, `compatibility-change`, and many `bugfix-spec` scenarios.

## Output

Generate:
- `prd.md`
- `impact-analysis.md`
- `baseline-references.md`
- `change-checklist.md`
- `open-questions.md`

## Rules

- Use the incremental template.
- Always include current-state summary.
- Always describe what stays unchanged.
- Always list affected modules, pages, APIs, entities, and events when known.
